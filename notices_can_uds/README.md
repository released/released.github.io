# notices_can_uds

UDS, ISO-TP, and ECU bootloader knowledge base.

- Published page: <https://released.github.io/notices_can_uds/>
- Branch: `gh-pages`
- Entry page: `index.html`
- Content pages: `index.md` and each section's `index.md`
- Role model: `roles/index.md`
- Protocol stack: `layers/index.md`

The repository is intentionally separate from `notices_can`, which contains
CAN/CAN FD material.

Published references must use public online sources. Private filesystem paths and
unpublished notes are not cited. All explanatory text, tables, and diagrams are
independently written; external material is linked for verification rather than copied.
